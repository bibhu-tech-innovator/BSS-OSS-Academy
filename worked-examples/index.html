How to Use These Examples

  • Start with the Architecture Overview to understand the network topology, system zones, and interface demarcation points. Toggle SOM Touchpoints to see where orchestration reaches into the network.
  • Walk through the step-by-step workflow — click each step to see systems involved, inputs/outputs, and which eTOM L2/L3 capability owns that process.
  • Review the Step-to-eTOM table for a complete mapping of every step to its eTOM process capability.
  • Expand the BPMN Workflow at the bottom to see the swim-lane process flow across COM, SOM, ROM, and External lanes — including parallel gateways and the point of no return.
