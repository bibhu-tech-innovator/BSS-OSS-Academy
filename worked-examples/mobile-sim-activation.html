Domain Examples/Mobile SIM Activation

Mobile SIM Activation

SOM-centric orchestration flow for activating a new 4G postpaid mobile subscription. Demonstrates how the Service Order Management layer receives a commercial order, validates, decomposes, coordinates resource allocation, triggers downstream provisioning (HSS, PCRF, OCS) via activation adapters, confirms responses, updates inventory, and notifies billing and CRM.

Architecture Overview

A 4G postpaid activation provisions a subscriber profile across the mobile core. The SIM authenticates via the HSS, data policies are enforced by the PCRF, and real-time charging is managed by the OCS. SOM orchestrates provisioning across all core network elements.

Subscriber Device

Handset with SIM card. On power-up the device attaches to the radio network and authenticates against the core.

Radio Access (eNodeB)

LTE base station providing air interface. Connects to the EPC via S1 interface for signalling and user-plane traffic.

EPC Core

MME handles signalling, SGW/PGW route user-plane data. The PGW is the anchor for IP connectivity and policy enforcement.

Subscriber Data

HSS stores subscriber profiles and auth keys. PCRF enforces QoS and usage policies. OCS manages real-time charging and balance.

Services & Billing

Billing/mediation collects CDRs. SLM tracks the subscription lifecycle. CRM/portal provides customer self-service.
